# Android-Store
Android Store is a lightweight, fast, and user-friendly App Store designed for Android users. It works both as a website and a installable app (PWA). Explore apps, Check all versions, And download APKs directly with a clean and simple interface. 
## Features

- Simple and clean interface  
- Download APKs directly  
- “All Versions” button for every app  
- Works as a website  
- Installable as a PWA  
- Fast loading and lightweight  
- Easy to update using GitHub
